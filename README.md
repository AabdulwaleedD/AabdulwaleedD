# 🧠 How I Think About Technology

I don't want to build software simply because I can write code.

I want to understand:

- **What problem are we solving?**
- **Who will use the solution?**
- **What are the business rules?**
- **What happens when the data is incomplete or wrong?**
- **How can the process be automated?**
- **How will the system be maintained?**
- **How can the result actually help the user?**

That mindset influences how I approach both analytics and software projects.

> **Good data work is not just about producing numbers. Good automation is not just about writing code. The goal is to build something useful.**
